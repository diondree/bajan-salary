# Bajan Salary

A Barbados salary and payroll calculator that helps employees estimate take-home pay after local statutory deductions.

## Why I built it

Barbadian employees often have difficulty quickly understanding how salary, NIS, PAYE and other deductions translate into monthly take-home pay.

This project provides a simple local calculator and is kept updated as statutory rates change.

## Features

- Barbados salary calculations
- NIS calculations
- Tax/deduction estimation
- Responsive interface
- Updated for current statutory rates

## Technical Overview

- React
- JavaScript
- Client-side calculations
- Automated deployment

## Maintenance

The calculator has been maintained over multiple years and updated as Barbados payroll rules change.
